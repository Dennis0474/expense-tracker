# Expense Tracker

🔗 [Live Demo] (https://dennis0474.github.io/expense-tracker/)

A vanilla JavaScript expense tracker built without any frameworks or libraries.

## Features
- Add income and expense transactions
- Filter transactions by category
- Live balance, income and expense totals
- Persists data across page refreshes using localStorage

## Tech Used
- HTML
- CSS
- Vanilla JavaScript (Classes, OOP, DOM manipulation, localStorage)

## How to Run
Clone the repo and open `index.html` in your browser. No install needed.
